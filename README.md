# Crackout — ガラスのブロック崩し

ボールが当たるたびにひびが走り、最後は音を立てて砕け散る。ガラスのブロックを割っていく、ブラウザのブロック崩し。

**▶ [ブラウザで遊ぶ](https://tinkling-way-games.github.io/crackout/)** — インストール不要。PC のキーボード・マウスでも、スマホのタッチでも遊べる。

![ガラスのブロック。上2段は厚いガラスで、いくつかにひびが入っている。中央では割れたブロックの破片が散っている](docs/images/screenshot.png)

## ガラスを割る手ざわり

- **ひびが育つ**: ボールが当たった点から放射状にひびが入り、当たるたびに増えていく。ひびだらけのブロックは割れる寸前
- **厚みで強さが分かる**: 強いブロックほどガラスが厚く、縁の線が 1〜3 本重なって見える。色ではなく厚みで硬さを表している
- **割れる音**: ひびが入るときは亀裂音、割れるときは鉄筋を叩いたような「カーン」という金属音
- **破片が散る**: 割れたガラスはボールの進む向きへ飛び散り、重力で落ちていく

## 遊び方

| 操作 | キーボード | マウス / タッチ |
| --- | --- | --- |
| パドル移動 | `←` `→` / `A` `D` | カーソル・指の位置に追従 |
| 発射 / 次へ | `Space` / `Enter` | クリック / タップ |
| 一時停止 | `P` / `Esc` | (タブを離れると自動で停止) |
| 消音 | `M` | |

- ライフは3機。全3ステージ
- パドルの上面はゆるい曲面で、端で打つほど角度が付く (最大60°)
- ブロックに当てるたびにボールは少しずつ速くなる

### パワーアップ

ブロックを割ると、ときどきアイテムが落ちてくる。パドルで受け取ると発動する。

| アイテム | 効果 | 持続 |
| --- | --- | --- |
| **W** (紫) | パドルが 1.5 倍に広がる。残り2秒で点滅 | 15秒 (再取得で加算、最大30秒) |
| **M** (桃) | 画面上のボールがそれぞれ3つに分裂 (最大12個)。全部落とすまでミスにならない | 落とすまで |
| **P** (赤) | ボールがブロックを反射せずに突き抜け、耐久値に関係なく一撃で割る | 8秒 (再取得で加算、最大16秒) |

ミスするかステージが変わると、効果と落下中のアイテムはリセットされる。

![3つの効果が同時に発動し、貫通ボールがブロックを突き抜けている画面](docs/images/powerups.png)

### ハイスコア

ゲームオーバーかオールクリアで、スコアが上位5件のランキングに記録される (到達ステージと日付つき)。画面右上の **HI** がベストスコアで、今のプレイがそれを超えると金色になる。

記録はブラウザの中 (localStorage) にだけ保存され、サーバーには送らない。端末・ブラウザごとに別々になる。

![ゲームオーバー画面。今回の2400点が3位に入り、金色で強調されている](docs/images/highscore.png)

## Claude Code で全自動で作ったゲーム

このゲームは、[Claude Code](https://claude.com/claude-code) が自走で作った。人間が出したのは、ブロックをガラス風にする・パワーアップを入れるといった要望と、GitHub 側の設定・PR のマージだけで、ゲームのコードは1行も人間が書いていない。

- **設計から公開まで**: 計画 → テストと実装 → 検証 → セルフレビュー → 作業記録 → PR を Claude Code が1サイクルで回した
- **検証が通るまで終わらせない**: 型チェック・ユニットテスト (92件)・ブラウザでの E2E を1本のスクリプトにまとめ、通らなければ「完了」と言えない仕組みにしてある
- **判断の記録が残っている**: なぜその作りにしたか (物理のすり抜け対策、角の反射の決め方など) は [`docs/PROGRESS.md`](docs/PROGRESS.md) に、タスクと受け入れ条件は [`docs/TASKS.md`](docs/TASKS.md) にそのまま残っている

自走させるための仕組み (ルール・hooks・スキル・権限の設計) は [`docs/AUTONOMOUS_DEV.md`](docs/AUTONOMOUS_DEV.md) にまとめた。言語非依存のテンプレートとして、ほかのプロジェクトにも使い回せる。

## 技術メモ

- TypeScript + Canvas 2D。実行時の依存パッケージはゼロ (フレームワーク・ゲームエンジンなし)
- 効果音は音声ファイルを使わず、Web Audio でその場で合成している
- 物理は 120Hz の固定ステップ。ブロックの角をかすめたときの反射は、入射角と位置の組み合わせを総当たりにしたテストで確かめている

手元で動かす方法・コードの構成・公開の手順は [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md) を参照。
