# steward: PR 運用ルール

- ブランチ名: `feat/<短い説明>` / `fix/<短い説明>`。Claude のクラウドセッションでは指定されたブランチを使う。
- 自分で作ったブランチでは rebase してよい。他人のブランチでは merge のみ (履歴を書き換えない)。
- CI が落ちたら、まずローカルで `scripts/verify.sh` を実行して再現させてから直す。
- テストの skip・削除・閾値緩和で緑にしない。
- レビューの小さな指摘 (命名、テスト追加、局所的なリファクタ) はそのまま直して push する。設計に関わる大きな指摘は、方針案を返信して人間の判断を待つ。
- マージは人間が行う。Claude は承認もマージもしない。
