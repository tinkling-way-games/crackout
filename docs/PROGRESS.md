## 2026-09-26 パドルを曲面に
- きっかけ: ユーザーの「反射角度を考えるとバーは実は曲面では」という気づき。検討の結果、真上から落ちるボールについては「端で30°傾いた円弧 (半径 = 幅、盛り上がり = 幅 × 0.134 ≒ 15px)」と等価。斜め入射では本物の曲面 (出射 = 2θ + 入射) と異なり、今の方式は入射角を無視する。選択肢を3つ示し、ユーザーは「見た目を曲面にする」を選んだ
- やったこと:
  - `paddleSurfaceY` (曲面の高さ) と `touchesPaddle` (曲面への接触判定) を physics.ts に追加。打ち返し時はボールを曲面に接する高さへ置く
  - 描画をドーム形に (上面は物理と同じ円弧、ハイライト付き)。拡大中も同じ比率で曲がる
  - テスト: 曲面の形、円弧の傾きから出る反射角と実際の打ち返し角の一致 (差 1.5° 未満)、端で低い位置で打ち返すこと (57 → 63件)
- 判断と理由: 見た目だけ曲面にすると、平らな当たり判定のままでは端で最大 15px 空中で跳ね返って見える (ボール直径 16px)。そのため角度は変えずに接触の高さだけ曲面に合わせた。接触は「ボール下端が真下の曲面に届いたか」で近似 (傾き最大30°なので誤差は1px程度)
- 残課題 / 次にやること: 本物の曲面反射 (入射角を反映) は未実装。遊んでみて物足りなければ検討。ハイスコア保存、GitHub Pages デプロイ

## 2026-09-26 ガラスのブロック (割れ目・破片・金属音)
- やったこと:
  - ブロックを1色の半透明ガラスに (グラデーション、斜めの映り込み、上辺のハイライト)。耐久値で色を変えるのをやめた

  - 演出 (DOM に依存しない純粋モジュール `src/fx/`): `crackPattern` は当たった点から内側へ扇形に伸びるひびを、ブロック位置と当たり順から決まる乱数で作る (毎フレーム同じ形)。`shards` は三角形の破片を、ボールの進む向き + 外向きに飛ばし、重力で落として寿命で消す (上限500)
  - 音: 割れる音は両端自由の金属棒の固有振動 (1 : 2.756 : 5.404 : 8.933) を合成した「カーン」+ 打撃ノイズ + きらめき。ひびの音は短い帯域ノイズの「ピキッ」。同時に鳴る金属音は6つまで
  - テスト: ひびの決定性・内向き・当たるたびに増えること、破片の数・向き・重力・寿命・上限、当たり点と broken の記録 (63 → 74件)。E2E に破片が出ることの確認を追加
- 判断と理由:
  - 色をなくすと未被弾の耐久1〜3が見分けられないため、初期の強さは「ガラスの厚み」(縁の線 1〜3本と不透明度) で表した。脆さ (残り耐久) はひびで表す
  - 破片の向きは最初、ボールの反射後の速度を使っていて、ボール側へ戻るように飛んでいた。スクリーンショットで気づき、反射前の速度 (ガラスを押し抜く向き) に修正し、テストで固定した
  - 当たり点は常に縁なので、全方位にひびを伸ばすと半分がブロック外に出て切り取られていた。内側へ ±76° の扇形に変更
  - 音はヘッドレス環境で聴けないため、OfflineAudioContext で描画してスペクトルを確認した (基音と 2.756 倍・5.404 倍に強い成分、整数倍 (2倍・3倍) にはほぼ無い = 金属的な非整数倍音)
- 残課題 / 次にやること: 実機で音色の好み (高さ・余韻の長さ) を確認してもらう。ハイスコア保存、GitHub Pages デプロイ
